# gogola89.github.io

Personal portfolio of George Ogola — Senior Full-Stack Software Engineer.

Plain HTML + CSS, no build step. Served by GitHub Pages at https://gogola89.github.io.

```
index.html      the page
favicon.svg
contact.json    machine-readable contact card (curl gogola89.github.io/contact.json)
assets/         portrait (webp + jpg for social previews) and CV PDF
.nojekyll       serve files as-is, skip Jekyll
```

Preview locally: `python3 -m http.server 8000` then open http://localhost:8000.
